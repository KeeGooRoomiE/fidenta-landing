# Открытые вопросы по проекту

Состояние на **27.10.2026** (версия страницы после мобильных правок дизайнера; дальше — правки под ПК).
Документ для дизайнера, заказчика и разработчиков: что нужно уточнить, прислать или решить,
чтобы довести лендинг до финальной версии. Закрытые пункты вычёркиваем (`~~...~~`) или удаляем.

Условные обозначения: **[Клиент]** — нужен ответ/данные заказчика, **[Дизайн]** — решение или макет
дизайнера, **[Разработка]** — доступы/техническое решение.

## 7. Заявка (CTA) — отправка письма не подключена

Форма «Заявка» собирает и проверяет данные, но запрос не отправляет (`TODO(CTA)` в `src/components/sections/CtaForm.astro`). Нужно:

1. **Доступы SMTP** для отправки писем (секреты в GitHub Secrets, не в коде). **[Разработка/Клиент]**
2. **Целевые почты**: адрес получателя для «инвестора» и для «собственника» (переключатель уже передаёт скрытое поле `audience`). **[Клиент]**
3. **Способ вызова воркфлоу `cta-email.yml` из браузера**: токен GitHub нельзя хранить в клиентском коде — нужен прокси / serverless-эндпоинт (или другой механизм). **[Разработка]**
4. Поведение после отправки (сообщение об успехе, очистка формы, защита от спама). **[Дизайн/Разработка]**
